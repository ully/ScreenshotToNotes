# 快捷指令设置详细指南

本文档详细说明如何设置「截取屏幕时」快捷指令自动化。

## 为什么需要快捷指令？

iOS 系统不允许第三方 App 直接监听系统截图事件。通过快捷指令自动化，我们可以：

1. 在系统截图时立即触发
2. 调用 App 的 App Intent
3. 自动打开 App 并显示分类选择框

这是目前唯一的**自动触发**方案。

## 完整设置步骤

### 第一步：导入快捷指令

1. 打开 ScreenshotToNotes App
2. 在引导页面点击「导入快捷指令」按钮
3. 自动跳转到快捷指令 App
4. 显示快捷指令预览界面
5. 点击「添加快捷指令」

**快捷指令内容：**
```
操作 1：获取最新照片
  - 类型：截屏
  - 数量：1

操作 2：运行 App Intent
  - App: ScreenshotToNotes
  - Intent: 处理最新截图
  - 输入：最新照片
```

### 第二步：创建自动化

1. 打开「快捷指令」App
2. 点击底部「自动化」标签
3. 点击右上角 `+` 号
4. 选择「创建个人自动化」

### 第三步：选择触发条件

在「何时」页面：

1. 向下滚动找到「截取屏幕时」
2. 点击选择
3. 点击「下一步」

### 第四步：添加操作

在「做什么」页面：

1. 搜索栏输入「截图存到备忘录」
2. 点击刚导入的快捷指令
3. 点击「下一步」

### 第五步：关闭「运行前询问」⚠️

**这是最关键的一步！**

在确认页面：

1. 找到「运行前询问」开关
2. **关闭**这个开关（灰色状态）
3. 点击「完成」

如果不关闭，每次截图都会弹出确认框，失去「自动」的意义。

### 第六步：验证设置

1. 按音量+ 和电源键截图
2. 应该立即打开 ScreenshotToNotes App
3. 显示分类选择框
4. 选择分类或等待自动保存

## 常见问题

### Q1: 找不到「截取屏幕时」选项

**原因：** iOS 版本过低

**解决：** 升级到 iOS 17.0 或更高版本

---

### Q2: 每次截图都弹出「要运行吗？」确认框

**原因：** 没有关闭「运行前询问」

**解决：**
1. 打开「快捷指令」App
2. 进入「自动化」标签
3. 找到「截取屏幕时」自动化
4. 点击进入
5. 关闭「运行前询问」开关

---

### Q3: 截图后没有反应

**可能原因：**

1. **自动化未启用**
   - 检查「快捷指令」→ 自动化
   - 确认「截取屏幕时」旁边是绿色开关

2. **快捷指令选择错误**
   - 检查自动化中选择的快捷指令名称
   - 应该是「截图存到备忘录」或导入时的名称

3. **App 未授权照片权限**
   - 设置 → ScreenshotToNotes → 照片
   - 选择「所有照片」

---

### Q4: 快捷指令导入链接失效

**临时解决方案：**

手动创建快捷指令：

1. 打开「快捷指令」App
2. 点击右上角 `+` 创建新快捷指令
3. 添加操作：
   - 搜索「获取最新照片」→ 类型选「截屏」
   - 搜索「打开 App」→ 选择「ScreenshotToNotes」
4. 保存快捷指令，命名为「截图存到备忘录」
5. 按正常流程创建自动化

**注意：** 手动创建的快捷指令可能无法调用 App Intent，建议联系开发者获取最新导入链接。

---

### Q5: 可以用 Siri 触发吗？

**可以，但不是主路径。**

1. 打开「快捷指令」App
2. 找到「截图存到备忘录」快捷指令
3. 点击设置 → 添加到主屏幕 / 添加到 Siri

之后可以：
- 说「嘿 Siri，截图存到备忘录」
- 点击主屏幕快捷方式图标

但这需要手动触发，不是截图后自动运行。

## 进阶设置

### 辅助触控绑定

如果你使用辅助触控（AssistiveTouch）：

1. 设置 → 辅助功能 → 触控 → 辅助触控
2. 打开辅助触控
3. 自定顶层菜单
4. 添加「快捷指令」→ 选择「截图存到备忘录」

这样点击辅助触控浮窗也可以触发处理。

### 背面轻点绑定

1. 设置 → 辅助功能 → 触控 → 背面轻点
2. 选择「轻点两下」或「轻点三下」
3. 选择「快捷指令」→「截图存到备忘录」

这样轻拍手机背面也可以触发（需要设备支持）。

### 控制中心快捷方式

1. 设置 → 控制中心
2. 向下滚动找到「快捷指令」
3. 点击绿色 `+` 添加
4. 从控制中心可快速访问快捷指令

## 故障排查清单

遇到问题时，依次检查：

- [ ] iOS 版本 ≥ 17.0
- [ ] 已导入「截图存到备忘录」快捷指令
- [ ] 已创建「截取屏幕时」自动化
- [ ] 已**关闭「运行前询问」**
- [ ] 自动化开关是绿色（已启用）
- [ ] App 已授权照片权限
- [ ] App 未被系统杀掉（尝试重启 App）

如果以上都正常仍无反应：

1. 删除现有自动化
2. 删除并重新导入快捷指令
3. 重新创建自动化
4. 重启手机

---

## 隐私说明

快捷指令和自动化：

- ✅ 仅在你截图时触发
- ✅ 仅访问最新一张截图
- ✅ 不会上传或分享你的截图
- ✅ 所有处理均在设备本地完成（OCR 使用系统 Vision）

自动化可随时在「快捷指令」App 中删除或禁用。
