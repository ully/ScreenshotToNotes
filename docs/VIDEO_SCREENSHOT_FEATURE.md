# 视频截图归档功能

## 功能概述

ScreenshotToNotes 现在支持智能识别和归档视频平台截图，特别优化了抖音、快手、B站、小红书等短视频平台的内容提取。

### ✅ 国内平台

| 平台 | 识别能力 | 提取信息 |
|-----|---------|---------|
| 🎵 抖音 | ✅ | 作者、时长、点赞数、评论数、话题标签 |
| 📹 快手 | ✅ | 作者、时长、互动数据 |
| 📺 哔哩哔哩 | ✅ | UP主、时长、投币/点赞数据 |
| 📖 小红书 | ✅ | 作者、话题标签、互动数据 |
| 🍉 西瓜视频 | ✅ | 基础信息提取 |

## 新增功能

### 1. 视频专属分类

除了原有的分类，新增三个视频专属分类：

- **视频收藏** 🎬 - 一般性视频内容
- **教程视频** 🎓 - 教学、攻略类视频
- **娱乐视频** ✨ - 搞笑、娱乐类视频

### 2. 智能视频类型识别

自动识别视频内容类型：

| 类型 | 关键词示例 | 自动分类 |
|-----|-----------|---------|
| 教程 | 教程、教学、步骤、攻略 | → 教程视频 |
| 美食 | 美食、做菜、食谱、烹饪 | → 视频收藏 |
| 健身 | 健身、运动、锻炼、减肥 | → 视频收藏 |
| 娱乐 | 搞笑、段子、有趣 | → 娱乐视频 |
| 科技 | 科技、数码、测评 | → 视频收藏 |
| 美妆 | 美妆、化妆、护肤 | → 视频收藏 |
| Vlog | vlog、日常、生活 | → 娱乐视频 |
| 音乐/舞蹈 | 音乐、唱歌、跳舞 | → 娱乐视频 |

### 3. 视频信息提取

#### 作者信息
- 抖音：@用户名
- 快手：快手号
- B站：UP主
- 小红书：小红薯

#### 视频数据
- 时长（如 3:45）
- 点赞数（如 12.5万）
- 评论数
- 分享数
- 播放量

#### 话题标签
- 自动提取 # 话题
- 支持中英文标签

## 工作流程

```
截图视频平台内容
  ↓
系统截图或快捷指令触发
  ↓
OCR 识别文字
  ↓
平台识别（抖音/快手/B站等）
  ↓
视频信息提取
  ├─ 作者
  ├─ 时长
  ├─ 互动数据
  └─ 话题标签
  ↓
视频类型判断
  ↓
智能分类（教程/娱乐/收藏）
  ↓
生成结构化笔记
  ↓
保存到备忘录
```

## 已知限制

### 识别准确度

- 依赖 OCR 识别质量
- 复杂界面布局可能影响提取
- 非标准格式的数据可能遗漏

### 平台支持

- 主要优化短视频平台
- 长视频平台（优酷、腾讯视频等）支持有限
- 需要界面包含明显平台标识

### 数据提取

- 统计数据需要在截图中可见
- 部分平台UI改版可能影响识别
- 纯图片视频（无文字）提取有限

## 常见问题

### Q: 为什么无法识别某个视频平台？

A: 确保截图包含平台特征文字（如"抖音号"、"UP主"等）。如果是新平台，可以提交反馈帮助我们添加支持。

### Q: 作者信息提取不准确？

A: 检查截图中作者信息是否清晰可见。建议截图包含完整的用户名区域。

### Q: 视频数据（点赞数）未提取？

A: 确保截图包含数据区域，且文字清晰。部分平台使用图标显示数据，OCR 可能无法识别图标。

### Q: 分类不准确？

A: 在筛选框中可以手动修改分类。同时可以在设置中调整分类映射规则。
